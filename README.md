This project is a 2-pass SIC assembler. 

An Assembler takes assembly code and converts it into object code, it's a crucial step in the process of a compiler to convert written program code into an executable. 
<img width="852" height="358" alt="sic3" src="https://github.com/user-attachments/assets/2ae8ca14-afa6-4067-ac3d-23a034cfd5ed" />

In the first pass the assembler creates a symbol table and performs a collection of 
checks to ensure the program isn't invalid in some way. 

In the 2nd pass the assembler uses the symbol table to produce the object code
along with some additional checks.
